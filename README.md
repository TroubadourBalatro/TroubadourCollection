# Troubadour's Mod Collection

A collection of mods for Balatro. Steammodded not requried. Tested on Version 1.0.1f. All ideas are original, Claude Code helped with implementation.

To use, download the folder corresponding to the mod, then move the folder into `%appdata%/Balatro/Mods`, i.e. `%appdata%/Balatro/Mods/RandomEternals`.
